Filter function for `#gbfm`

```ts
function extractGbfmPosts(data) {
  return data.feed
    .filter(item => 
      item.post.record.facets.some(facet => 
        facet.features.some(feature => feature.tag === 'gbfm')
      )
    )
    .map(item => item.post.record.text);
}

```
